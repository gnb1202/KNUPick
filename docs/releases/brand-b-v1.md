# B 브랜드와 공지 집계 배포

2026-09-12. 사용자가 승인한 B 브랜드, 중앙 정렬 카피·검색, 캠퍼스 표기와 카테고리 이모지를 제품에 적용한다. 공지 영역은 사용자안을 기본으로 확정하고 누적 수 대신 최근 30일 수를 표시한다.

## 운영 기준과 포함 범위

운영 배포 `dpl_2D1GVhqiPHZ5RgE514y6bwb1yrjp`의 소스를 보존한 PR #5 (`a87e128b9f3a949dba75cb574dd9e680756e05fd`)에서 분리했다. 기존 작업 폴더의 v2 RAG·추천·인증 전환을 복사하지 않았다. 기존 로그인·북마크·추천 요청 계약과 챗봇 카드 순서 서명·토큰 폐기·원문 근거 렌더링을 유지한다. 챗봇은 심볼·색·표기만 바꾼다.

- 홈·헤더·카드·필터·검색·캘린더·로그인·회원가입·프로필과 앱 아이콘에 B 토큰을 적용한다.
- 새 공개 읽기 API `/api/posts/stats`는 정확한 HEAD count 두 개를 반환한다. `date`, `timeZone`, `todayCount`, `recentCount`가 응답 계약이다.
- 한국 날짜의 오늘과 이전 29일을 `posted_date >= 시작일 AND posted_date <= 오늘`로 조회한다. 본문 수집 시각은 집계에 사용하지 않는다. [Supabase 범위 필터](https://supabase.com/docs/reference/javascript/using-filters-gte)
- `/api/posts?posted=today`는 학과 분기 양쪽 모두 페이지네이션 전에 게시일을 제한한다. 검색·캠퍼스·카테고리·마감 숨기기를 계속 적용한다.
- 집계는 피드의 최대 200건 조회 및 화면 필터와 무관하다. 집계 실패는 0으로 표시하지 않는다. 표시 중인 탭에서 1분마다, 다시 활성화할 때 갱신한다.
- 새 환경 변수, DB 마이그레이션, 운영 패키지 변경은 없다. 공개 Supabase 클라이언트와 기존 RLS를 사용한다.

## 검증

- 고정 lockfile로 `npm ci` 완료. TypeScript·프로덕션 빌드 통과.
- Vitest 5개 파일·46개 테스트 통과. 최근 30일 양쪽 경계·한국 자정·미래/누락 날짜·200건 초과·집계 실패·오늘 필터를 포함한다.
- ESLint 오류 0개. 기존 미변경 파일의 사용하지 않는 변수 경고 3개가 남아 있다.
- 브라우저: 기본안과 비교 도구 숨김, 검색·카테고리·오늘 필터, 0건·재시도, 키보드 포커스·다크 테마, 320/390/768/1440px, 캘린더·로그인·회원가입 화면 통과.
- 기존 챗봇 UI 6개 시나리오: 카드 번호·토큰 왕복·원문 표시·SSE 중단·새 카드의 이전 토큰 폐기·잘못된 토큰 이후 복구 통과.
- 로컬 브라우저 검사는 모의 API이며 실제 계정 생성·북마크 쓰기·유료 모델 호출을 하지 않는다.
