2026-09-13 정리. 이 문서는 과거 검증 결과를 연결하는 공개 요약이며, 테스트 대화나 비공개 실행 기록을 포함하지 않습니다.

## 현재 관측의 해석

운영 기준 legacy 코드는 이후 별도의 알려진 질문 검증과 모의 모델·DB·UI 회귀 검증을 거쳤습니다. 현재의 실행 기록 기능은 질문, 실제 검색 조건, 근거, 답변, 모델·프롬프트·배포 버전을 연결합니다. 검색·추천 정책을 변경하지 않습니다.

완료율은 정답률이 아닙니다. 사용자 평가와 수동 검토는 별도이며 미평가를 긍정으로 계산하지 않습니다. 동의한 테스트 계정의 표본은 일반 사용자 만족도나 CTR을 대표하지 않습니다. 버전별 질문·날짜·원문이 다르므로 단순 비율 차이로 인과 효과를 주장하지 않습니다.

새로 확인한 실패는 원문과 판정 기준을 검수한 뒤 기존 회귀 자료에 추가해야 합니다. 관측 화면은 별도의 LLM 자동 채점이나 유료 평가를 실행하지 않습니다.
